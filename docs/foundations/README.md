# Fundamentos

As decisões de base do Design System do AVYN. Os valores estão em [`tokens/`](../../tokens/) e podem ser vistos renderizados no [showcase](../showcase/index.html).

| Documento | Do que trata |
|---|---|
| [Cor](color.md) | Papéis semânticos, regras do tint, dourado, estados, tipos de vinho |
| [Contraste](contrast.md) | Relatório gerado dos 88 pares de cor (não editar à mão) |
| [Tipografia](typography.md) | Playfair Display + DM Sans, estilos, Dynamic Type |
| [Layout e forma](layout.md) | Espaço, margens, toque, raios, profundidade |
| [Movimento](motion.md) | Transições do sistema, springs, Reduzir Movimento |
| [Ícones](iconography.md) | SF Symbols, tamanhos, quando desenhar um ícone próprio |

Princípio que vale para todos: **os controles são os do iOS; a marca vive na cor, na tipografia, no símbolo da taça-lupa e num único componente próprio, a janela de consumo.**
